# Product rules

## One clear model

Barkeep has three sections. They are always named the same way:

1. **Always visible**
2. **Hidden**
3. **Always hidden**

The Items screen shows these three sections at the same time. Each item has a
section menu. Drag and drop is a faster option, not the only option.

## Main actions

- Click the Barkeep dot: show or hide the Hidden section.
- Option-click the dot: show or hide all sections.
- Right-click the dot: open the short command menu.
- Use Search: find and open any known menu bar item.

The right-click menu contains only common actions. Settings holds the rest.

## Setup

Barkeep does not use a long onboarding flow.

1. Explain the three sections.
2. Register the request and open the exact Accessibility page.
3. Show a small switch guide over System Settings. The app tile is a drag fallback.
4. Show all items before the first arrangement.
5. Let the user assign items.
6. Hide the Hidden section when the user selects Done.

## Icons

The default is Dot. Built-in choices use small monochrome vector symbols:

- Dot
- Ring
- Ellipsis
- Diamond
- Chevrons
- Line
- Sparkle
- Grid

A custom image is optional. Barkeep copies it to its Application Support folder,
so the source file can move later.

## Defaults

- Click to reveal: on
- Auto-hide: on, after five seconds
- Hover to reveal: off
- Scroll to reveal: off
- Touch ID: off
- Second menu bar: off
- Menu bar style: off
- Item spacing changes: off
- Network and script triggers: off

These defaults keep idle work and surprise behavior low.
